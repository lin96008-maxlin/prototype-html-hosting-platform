## 推荐交付门槛

1. 所有自动检查与生产构建通过。
2. 新环境使用独立密码、密钥、域名、数据库和数据卷。
3. 演示数据中不含任何真实个人信息、客户资料或生产原型。
4. 关键业务流程通过浏览器自动化与人工验收。
5. 备份能够在隔离环境恢复，且回滚方案经过验证。
