# 同域路径接入说明

平台默认挂载在 `/manage`，适合与其他系统共用一个新域名。

## 必须保持一致

- 构建变量：`NEXT_PUBLIC_BASE_PATH=/manage`
- 运行变量：`NEXT_PUBLIC_BASE_PATH=/manage`
- 反向代理路径：`/manage/*`
- 健康检查：`/manage/api/health`

## Caddy 示例

```caddyfile
handle_path /manage/* {
  reverse_proxy app:3000
}
```

实际项目中的 `deploy/Caddyfile` 已处理路径前缀，部署时只需提供新 `SITE_DOMAIN`。若改成其他前缀，必须重新构建应用，并同步调整健康检查和代理配置。

## 验收地址

- 登录页：`https://新域名/manage/login`
- 公开原型：`https://新域名/manage/project/{code}`
- 分享原型：`https://新域名/manage/share/{code}`

不要把新平台代理到旧项目域名、旧容器网络或旧数据卷。
